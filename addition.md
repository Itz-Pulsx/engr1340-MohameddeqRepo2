 Line up the numbers: Stack the numbers vertically, ensuring the ones, tens, and hundreds columns are neatly aligned on top of each other.
 Start on the right: Begin adding the digits in the smallest place value column, which is the ones place.
 Regroup or carry over: If the sum of a column is 10 or more, write down the rightmost digit underneath the column line and carry the left digit (the tens value) over to the next column on the left.
 Move left: Proceed to the next column (tens, then hundreds, and so on), adding those digits along with any carried-over value.
 Finish the sum: Continue this process column by column from right to left until all place values are added
